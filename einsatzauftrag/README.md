# Einsatzauftrag

Füllt den THW-Einsatzauftrag (Vordruck *Fb Fü 3*) als PDF aus, einzeln mit Live-Vorschau
oder viele auf einmal aus einer Excel-/CSV-Datei. Alles läuft im Browser, nichts wird
hochgeladen.

Web-App von Johannes Rudolph ([wattnpapa/einsatzauftrag](https://github.com/wattnpapa/einsatzauftrag)),
hier als Home-Assistant-Add-on mit Ingress verpackt. Die App erscheint in der Seitenleiste
und ist durch die Anmeldung von Home Assistant geschützt.
